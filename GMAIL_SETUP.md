# Yasya — отправка желаний через Gmail SMTP

Сайт отправляет каждое желание с Gmail-адреса `davidkhayrov7777@gmail.com` на:
- lesnovrostislav45@gmail.com
- david.khayrov@gmail.com

Промежуточные почтовые платформы (Resend / EmailJS) не используются. Отправка выполняется серверной функцией Vercel через SMTP Gmail. Пароль не попадает в браузер.

## 1. Создайте пароль приложения Gmail

1. Войдите в Google-аккаунт `davidkhayrov7777@gmail.com`.
2. Включите двухэтапную аутентификацию (2-Step Verification), если она ещё не включена.
3. Откройте https://myaccount.google.com/apppasswords
4. Создайте пароль приложения, например с названием `Yasya Vercel`.
5. Скопируйте сгенерированный 16-значный пароль. Не отправляйте его в чат и не добавляйте в исходный код.

Если Google не показывает страницу паролей приложений, проверьте требования аккаунта Google: для некоторых типов управляемых/защищённых аккаунтов эта функция недоступна.

## 2. Добавьте переменные в Vercel

Vercel → проект `yasya-2` → Settings → Environment Variables:

- `GMAIL_USER` = `davidkhayrov7777@gmail.com`
- `GMAIL_APP_PASSWORD` = 16-значный пароль приложения (можно вставить без пробелов)

Отметьте Production (и Preview, если нужно), сохраните.

## 3. Опубликуйте обновлённый проект

Замените файлы проекта содержимым этого архива, установите зависимости (`npm install`), затем выполните Deploy в Vercel. После изменения Environment Variables обязательно сделайте новый deployment.

## 4. Проверка

Отправьте тестовое желание с опубликованного сайта. Оно должно прийти на оба адреса. В интерфейсе сайта при успешной отправке показывается только праздничный экран «Пусть все твои желания сбудутся ♡».

## Безопасность

- Не публикуйте пароль приложения в GitHub или frontend.
- Не присылайте пароль приложения в ChatGPT.
- Если пароль случайно раскрыт, удалите его в настройках Google и создайте новый.
